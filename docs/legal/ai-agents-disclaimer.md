## 1. AI Usage Overview

Phungu Insights incorporates **artificial intelligence** and **machine learning models** to provide market analysis, conversational interfaces, and data interpretation services. This disclaimer explains the nature, limitations, and appropriate use of AI-generated content.

## 2. Types of AI Used

### 2.1 Malawi Stock Exchange Chat Assistant (mse.today)

The MSE Today platform uses AI for:

| AI Capability | Description | Data Used |
|---------------|-------------|-----------|
| **AI Market Chat** | Natural language Q&A about MSE stocks | Live market data, fundamental data, index values, corporate actions |
| **AI Broker Order Drafting** | Generates order emails to licensed brokers | User input, selected counter, share price, broker details |
| **AI Brokerage Account Onboarding** | Generates introductory emails to brokers | User input, broker requirements |

### 2.2 Phungu Insights Agent (agent-app)

The local Agent application uses large language models (LLMs) for:

- Answering questions about Malawi Stock Exchange data
- Market data interpretation and summarization
- Document parsing and structured data extraction
- Technical assistance with deployments and troubleshooting

The Agent supports multiple providers: Ollama (local), OpenRouter, Google Gemini, and Groq.

## 3. AI Model Limitations

### 3.1 Hallucination and Errors

AI models, including large language models, can:

- Generate factually incorrect or fabricated information ("hallucinations")
- Produce answers with unwarranted confidence
- Misinterpret ambiguous queries
- Miss important context or produce inconsistent responses

### 3.2 No Real-Time Trading Data

AI responses in the Agent are based on **previously stored market data**, not real-time feeds. The most recent data available may differ from current market conditions.

### 3.3 Knowledge Cutoff

Models have knowledge cutoffs. While the Agent uses tools to fetch current data, model-based reasoning may rely on knowledge that is not current.

## 4. Appropriate Use of AI

### 4.1 Informational Purposes Only

AI-generated content is provided for **informational and educational purposes only**. It should not be:

- Relied upon as the sole basis for any decision
- Treated as a substitute for professional advice
- Used without independent verification

### 4.2 Human Oversight Required

For any material decision, you should:

1. **Independently verify** all information with primary sources
2. **Consult qualified professionals** (financial advisors, lawyers, accountants)
3. **Apply your own judgment** before acting
4. **Review all AI-generated drafts** before sending to third parties

### 4.3 Broker Order AI (MSE Today)

When using the AI to draft broker order emails:

- **You** are responsible for reviewing, verifying, and approving all order details
- The AI does not execute trades — it generates text for your manual review
- **Verify share counts, prices, and broker requirements** before sending
- The AI cannot account for market changes between drafting and sending

## 5. Data Input and Privacy

### 5.1 User Inputs

When you provide information to AI tools:

- Inputs are **not used to train** the underlying AI models
- Inputs are logged only to the extent necessary for the service to function
- See the [Privacy Policy](./privacy-policy.md) for data handling details

### 5.2 Sensitive Information

Do not provide:

- Personal identification numbers (NIN)
- Banking or brokerage account credentials
- Credit or debit card information

## 6. AI Output Usage

### 6.1 Original Content Generated

Content generated by AI tools:

- Is **not original research** — it synthesizes existing data and patterns
- May contain **unattributed summaries** of source material
- Should be **attributed** when shared publicly: "AI-generated summary based on data sourced from the Malawi Stock Exchange"

### 6.2 Commercial Use Limitations

AI-generated content:

- Inherits the non-commercial usage restrictions of the underlying market data
- Cannot be used for commercial gain without proper licensing
- Must comply with the [Data Usage Declaration](./data-usage-declaration.md)

## 7. No Investment, Legal, or Tax Advice

The AI does **not** provide:

- Investment advice or stock recommendations

Any AI-generated market commentary, model verdicts, or analysis should be independently verified. See the [Investment Disclaimer](./investment-disclaimer.md).

## 9. AI Transparency

### 9.1 Model Attribution

Where possible, the service identifies which provider generated the response:

- "Provider: gemini" — Google Gemini model was used
- "Provider: groq" — Groq-hosted model was used
- "Provider: openrouter" — OpenRouter model was used
- "Provider: ollama" — Local Ollama model was used
- "Provider: none" — No provider was available

### 9.2 Open Source Models

When using Ollama for local inference, models are run on the user's machine. No data is transmitted to third parties during local inference.
